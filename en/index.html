Clear Your Browser Cache

Step-by-step guides for all common browsers, versions and devices.

Google Chrome

Current versions Chrome 40 and newer

Windows / Linux

  1. Press Ctrl + Shift + Del (or: three-dot menu › Delete browsing data; in older versions: More tools › Clear browsing data).
  2. Set “Time range” to “All time”.
  3. Select “Cached images and files”. You can clear the other checkboxes.
  4. Click “Delete data” (older versions: “Clear data”).

macOS

  1. Press ⌘ Cmd + ⇧ Shift + ⌫ Delete.
  2. Set “Time range” to “All time”.
  3. Select “Cached images and files”.
  4. Click “Delete data” (older versions: “Clear data”).

Android

  1. Open Chrome and tap the three-dot menu to the right of the address bar.
  2. Tap “Delete browsing data” (older versions: “Clear browsing data”) and, if needed, “More options”.
  3. Set the time range to “All time” and select “Cached images and files”.
  4. Tap “Delete data”.

iPhone / iPad (iOS)

  1. Open Chrome and tap the three-dot menu.
  2. Tap “Delete browsing data” (older versions: “Clear Browsing Data”).
  3. Choose a time range and select “Cached Images and Files”.
  4. Confirm with “Delete browsing data” (older versions: “Clear Browsing Data”).
Older versions Chrome up to version 39 (approx.)

Windows / Linux

  1. Press Ctrl + Shift + Del.
  2. Under “Obliterate the following items from”, choose “the beginning of time”.
  3. Select “Empty the cache” and click “Clear browsing data”.

macOS

  1. Press ⌘ Cmd + ⇧ Shift + ⌫ Delete.
  2. Under “Obliterate the following items from”, choose “the beginning of time”.
  3. Select “Empty the cache” and click “Clear browsing data”.

Android

  1. Tap the browser’s menu button and choose “Settings”.
  2. Choose “Privacy” and then “Clear browsing data”.
  3. Select “Clear the cache” and tap “Clear”.

Microsoft Edge

Current versions (computer) Edge 79 and newer (Chromium)

Windows / Linux

  1. Press Ctrl + Shift + Del.
  2. Set “Time range” to “All time”.
  3. Select “Cached images and files” and click “Delete now” (older versions: “Clear now”).
  4. Without the shortcut: “Settings and more” (…) › Settings › Privacy, search, and services › Delete browsing data (older versions: Clear browsing data) › “Choose what to clear”.

macOS

  1. Press ⌘ Cmd + ⇧ Shift + ⌫ Delete.
  2. Set “Time range” to “All time”.
  3. Select “Cached images and files” and click “Delete now” (older versions: “Clear now”).
  4. Without the shortcut: “Settings and more” (…) › Settings › Privacy, search, and services › Delete browsing data (older versions: Clear browsing data) › “Choose what to clear”.
Edge app Android and iPhone / iPad

Android / iOS

  1. Tap the menu (…).
  2. Choose Settings › Privacy and security › “Delete browsing data”. Depending on the app version, the entry is called “Privacy” or “Privacy and security”, and “Clear browsing data” in older versions.
  3. Select the data types you want to delete, including the cache (cached images and files).
  4. Tap “Delete” (older versions: “Clear”).
Edge Legacy Edge versions 12 to 18 (EdgeHTML, Windows 10)

Windows 10

  1. Press Ctrl + Shift + Del – or open the menu (…) › Settings › “Choose what to clear”.
  2. Select “Cached data and files”.
  3. Click “Clear”.

Mozilla Firefox

Current versions Firefox 57 and newer

Windows / Linux

  1. Press Ctrl + Shift + Del. The “Clear Recent History” dialog opens.
  2. Next to “Time range to clear” (or “When”), choose “Everything”.
  3. Select “Cache” (newer versions: “Temporary cached files and pages”) and click “OK”, “Clear Now” or “Clear”.
  4. Without the shortcut: menu (☰) › Settings › Privacy & Security › “Browsing data” (older versions: “Cookies and Site Data”) › “Clear browsing data” (or “Clear Data…”) › “Temporary cached files and pages” › “Clear”.

macOS

  1. Press ⌘ Cmd + ⇧ Shift + ⌫ Delete. The “Clear Recent History” dialog opens.
  2. Next to “Time range to clear” (or “When”), choose “Everything”.
  3. Select “Cache” (newer versions: “Temporary cached files and pages”) and click “OK”, “Clear Now” or “Clear”.
  4. Without the shortcut: Firefox menu in the menu bar › Settings › Privacy & Security › “Browsing data” (older versions: “Cookies and Site Data”) › “Clear browsing data” (or “Clear Data…”).

Android

  1. Tap the three-dot menu and choose “Settings”.
  2. Tap “Delete browsing data” (older versions: “Privacy and Security” › “Clear private data”).
  3. Select “Cached images and files”.
  4. Tap “Delete browsing data” at the bottom and confirm with “Delete”.

iPhone / iPad (iOS)

  1. Open the menu and choose “Settings”.
  2. Under “Privacy”, tap “Data Management”.
  3. Select “Cache” and tap “Clear Private Data” at the end of the list.
Older versions Firefox up to version 56

Windows / Linux / macOS

  1. Press Ctrl + Shift + Del (macOS: ⌘ Cmd + ⇧ Shift + ⌫ Delete), choose “Everything” and select “Cache”.
  2. Without the shortcut: menu (☰) › Options › Advanced › Network › “Cached Web Content” › “Clear Now”.

Android (older app)

  1. Tap the menu icon and then “Settings”.
  2. Under “Privacy & Security”, choose “Clear private data”.
  3. Select “Cache” and tap “Clear data”.

Safari

Mac Safari 6 and newer (macOS)

macOS

  1. Show the Develop menu once: Safari › Settings › Advanced › “Show features for web developers” (older versions: “Show Develop menu in menu bar”).
  2. In the menu bar, choose “Develop” › “Empty Caches” – or press ⌘ Cmd + ⌥ Option + E.
  3. Alternatively (also deletes cookies): Safari › Settings › Privacy › “Manage Website Data…” › “Remove All”.
iPhone / iPad iOS 18 and newer

iOS / iPadOS

  1. Open your device’s “Settings” and tap “Apps” › “Safari”.
  2. Scroll down and tap “Clear History and Website Data”. Confirm the time range with “Clear History”.
  3. Website data only, without history: Safari › “Advanced” › “Website Data” › “Remove All Website Data”.
iPhone / iPad (older) iOS 17 and older

iOS / iPadOS

  1. Open your device’s “Settings” and choose “Safari”.
  2. Tap “Clear History and Website Data” and confirm.
  3. Website data only: “Advanced” › “Website Data” › “Remove All Website Data” and confirm with “Remove Now”.
Older versions Safari 5 and older (Mac and Windows)

macOS

  1. Open the “Safari” menu and choose “Empty Cache…”.
  2. Then click “Empty”.

Windows

  1. Press Ctrl + Alt + E.
  2. Then click “Empty”.

Opera

Current versions Opera 36 and newer

Windows / Linux / macOS

  1. Press Ctrl + Shift + Del (macOS: ⌘ Cmd + ⇧ Shift + ⌫ Delete; or: Opera menu › Settings › Privacy & security › “Clear browsing data…”).
  2. Set the time range to “All time” (older versions: “the beginning of time”).
  3. Select “Cached images and files” and click “Delete data” (older versions: “Clear browsing data”).
Early Chromium versions Opera 15 to 35

Windows / Linux / macOS

  1. Click the Opera or menu button in the browser window’s title bar.
  2. In the menu, click “Settings” and then “Clear browsing data…”.
  3. Select the option “Empty the cache”.
  4. Click “Clear browsing data” at the bottom of the window.
Older versions Opera up to version 12 (Presto)

Windows

  1. Opera 11 and 12: Opera menu › Settings › “Delete Private Data…” (shortcut Ctrl + Shift + Del).
  2. Opera 9 and 10: “Tools” menu › “Delete Private Data…”.
  3. Click “Detailed options”, select “Delete entire cache” and click “Delete”.

Brave

Current versions Brave for computer and Android

Windows / Linux

  1. Press Ctrl + Shift + Del – or enter brave://settings/clearBrowserData in the address bar.
  2. Without the shortcut: menu (☰) › Settings › Additional settings › Privacy and security › “Delete browsing data” (older versions: “Clear browsing data”).
  3. Choose a time range (e.g. “All time”) and select “Cached images and files”.
  4. Click “Delete data” (older versions: “Clear data”).

macOS

  1. Press ⌘ Cmd + ⇧ Shift + ⌫ Delete – or enter brave://settings/clearBrowserData in the address bar.
  2. Choose a time range (e.g. “All time”) and select “Cached images and files”.
  3. Click “Delete data” (older versions: “Clear data”).

Android

  1. Open Brave’s settings.
  2. Choose “Brave Shields and privacy” › “Clear browsing data”.
  3. Choose the data types (including the cache) and tap “Clear browsing data”.

Vivaldi

Current versions Vivaldi for computer

Windows / Linux

  1. Press Ctrl + Shift + Del – or open the Vivaldi menu › Tools › “Delete Browsing Data…”.
  2. Choose the time range “Everything”.
  3. Select “Cache” (and “Application Cache”) and click “Delete”.

macOS

  1. Press ⌘ Cmd + ⇧ Shift + ⌫ Delete – or choose “Delete Browsing Data…” from the “Tools” menu.
  2. Choose the time range “Everything”.
  3. Select “Cache” (and “Application Cache”) and click “Delete”.

Samsung Internet

Samsung Internet Android (Galaxy devices)

Android

  1. Open Samsung Internet and tap the menu icon (☰) at the bottom right.
  2. Tap “Settings” › “Personal browsing data” (older versions: “Personal data”) › “Delete browsing data”.
  3. Select “Cache” or “Cached images and files”.
  4. Tap “Delete data” (older versions: “Delete”) and confirm.

In older versions, you can find the function under Settings › Privacy and security › “Delete browsing data”.

Internet Explorer

Internet Explorer 9 to 11 Windows

Windows

  1. Press Ctrl + Shift + Del – or click the gear icon › Safety › “Delete browsing history…”.
  2. Clear “Preserve Favorites website data” and select “Temporary Internet files and website files”.
  3. Click “Delete”.

Instead of Internet Explorer, Microsoft recommends the Edge browser (with “Internet Explorer mode” if needed).

Internet Explorer 7 and 8 Windows

Windows

  1. Internet Explorer 8: Press Ctrl + Shift + Del or choose “Safety” › “Delete Browsing History…”.
  2. Internet Explorer 7: “Tools” › “Internet Options” › “General” tab › under “Browsing history”, click “Delete…”.
  3. Select “Temporary Internet files” and click “Delete”.
Internet Explorer 6 Windows

Windows

  1. Choose “Tools” › “Internet Options” › “General” tab.
  2. Under “Temporary Internet files”, click “Delete Files…”.
  3. Select “Delete all offline content” and confirm with “OK”.
