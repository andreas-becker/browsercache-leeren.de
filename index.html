Browsercache-leeren.de

 Google Chrome

  1. Drücken Sie die Tasten Strg⌘ Cmd + ⇧ Shift + Entf←
  2. Wählen Sie bei "Zeitraum" den Eintrag "Gesamte Zeit"
  3. Aktivieren Sie "Bilder und Dateien im Cache" und klicken Sie dann auf "Daten löschen"
  4. Alternativ lässt sich der Browsercache mit dem Programm CleanMyMac X* löschen.
  1. Klicken Sie auf den Menü-Knopf in der Titelleiste des Browserfenster
  2. Wählen Sie den Eintrag "Einstellungen"
  3. Im neuen Fenster wählen Sie den Eintrag "Datenschutz"
  4. Klicken Sie auf den Button "Browserdaten löschen"
  5. Es öffnet sich ein neues Fenster. Aktivieren Sie die Option "Cache leeren" und klicken Sie dann auf "Löschen"

 Mozilla Firefox

  1. Drücken Sie die Tasten Strg⌘ Cmd + ⇧ Shift + Entf←
  2. Wählen Sie in der Auswahlbox den Eintrag "Alles"
  3. Aktivieren Sie die Option "Cache" und klicken Sie dann auf "Ok"
  4. Alternativ lässt sich der Browsercache mit dem Programm CleanMyMac X* löschen.

 Microsoft Internet Explorer

  1. Drücken Sie die Tasten Strg⌘ Cmd + ⇧ Shift + Entf
  2. Wählen Sie "Temporäre Internetdateien" und klicken Sie dann auf "Löschen"
  3. Alternativ lässt sich der Browsercache mit dem Programm CleanMyMac X* löschen.

 Opera

  1. Klicken auf den Opera- bzw. Menü-Knopf in der Titelleiste des Browserfenster
  2. Klicken Sie im Menü "Einstellungen" auf "Internetspuren löschen..."
  3. Aktivieren Sie die Option "Den kompletten Cache löschen"
  4. Klicken Sie unten im Fenster auf den Button "Löschen"

 Opera

  1. Drücken Sie die Tasten Strg + ⇧ Shift + Entf
  2. Klicken Sie anschließend auf "Browserdaten löschen"

 Safari

  1. Drücken Sie die Tasten Strg⌘ Cmd + Alt + E
  2. Klicken Sie anschließend auf "Leeren"
  3. Alternativ lässt sich der Browsercache mit dem Programm CleanMyMac X* löschen.
  1. Öffnen Sie die "Einstellungen" Ihres iOS-Geräts
  2. Wählen Sie den Eintrag "Safari" und dann "Erweitert"
  3. Anschließend den Eintrag "Website-Daten"
  4. Klicken Sie den Button "Alle Website Daten entfernen" und bestätigen Sie die Abfrage mit "Entfernen"

 Webkit

  1. Drücken Sie die Tasten Strg⌘ Cmd + ⇧ Shift + Entf
  2. Es öffnet sich ein neues Fenster. Aktivieren Sie die Option "Cache" und klicken Sie dann auf "Jetzt löschen"
  1. Klicken Sie auf den Menü-Knopf in der Titelleiste des Browserfenster
  2. Wählen Sie den Eintrag "Einstellungen"
  3. Im neuen Fenster wählen Sie den Eintrag "Datenschutz & Sicherheit"
  4. Klicken Sie auf den Eintrag "Cache leeren" und bestätigen Sie die Abfrage mit OK
