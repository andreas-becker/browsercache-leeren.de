Zu den Anleitungen springen

Browsercache leeren

Schritt-für-Schritt-Anleitungen für alle gängigen Browser, Versionen und Geräte.

Browser auswählen

  • Google Chrome
  • Microsoft Edge
  • Mozilla Firefox
  • Safari
  • Opera
  • Brave
  • Vivaldi
  • Samsung Internet
  • Internet Explorer

Google Chrome

Aktuelle Versionen Chrome ab Version 40

Windows / Linux

  1. Drücken Sie die Tasten Strg + Umschalt + Entf (oder: Dreipunkt-Menü › Weitere Tools › „Browserdaten löschen“).
  2. Wählen Sie bei „Zeitraum“ den Eintrag „Gesamte Zeit“.
  3. Aktivieren Sie „Bilder und Dateien im Cache“. Die übrigen Häkchen können Sie entfernen.
  4. Klicken Sie auf „Daten löschen“.

macOS

  1. Drücken Sie die Tasten ⌘ Cmd + ⇧ Umschalt + ⌫ Rücktaste.
  2. Wählen Sie bei „Zeitraum“ den Eintrag „Gesamte Zeit“.
  3. Aktivieren Sie „Bilder und Dateien im Cache“.
  4. Klicken Sie auf „Daten löschen“.

Android

  1. Öffnen Sie Chrome und tippen Sie rechts neben der Adressleiste auf das Dreipunkt-Menü.
  2. Tippen Sie auf „Browserdaten löschen“ und, falls nötig, auf „Weitere Optionen“.
  3. Wählen Sie als Zeitraum „Gesamte Zeit“ und aktivieren Sie „Bilder und Dateien im Cache“.
  4. Tippen Sie auf „Daten löschen“.

iPhone / iPad (iOS)

  1. Öffnen Sie Chrome und tippen Sie auf das Dreipunkt-Menü.
  2. Tippen Sie auf „Browserdaten löschen“.
  3. Wählen Sie einen Zeitraum und aktivieren Sie „Im Cache gespeicherte Bilder und Dateien“.
  4. Bestätigen Sie mit „Browserdaten löschen“.
Ältere Versionen Chrome bis Version 39 (ca.)

Windows / Linux

  1. Drücken Sie die Tasten Strg + Umschalt + Entf.
  2. Wählen Sie bei „Zeitraum“ den Eintrag „Alles“ bzw. „Gesamte Zeit“.
  3. Aktivieren Sie „Cache löschen“ und klicken Sie dann auf „Browserdaten löschen“.

macOS

  1. Drücken Sie die Tasten ⌘ Cmd + ⇧ Umschalt + ⌫ Rücktaste.
  2. Wählen Sie bei „Zeitraum“ den Eintrag „Alles“ bzw. „Gesamte Zeit“.
  3. Aktivieren Sie „Cache löschen“ und klicken Sie dann auf „Browserdaten löschen“.

Android

  1. Tippen Sie auf den Menü-Knopf des Browsers und wählen Sie „Einstellungen“.
  2. Wählen Sie „Datenschutz“ und dann „Browserdaten löschen“.
  3. Aktivieren Sie „Cache leeren“ und tippen Sie auf „Löschen“.

Microsoft Edge

Aktuelle Versionen (Computer) Edge ab Version 79 (Chromium)

Windows / Linux

  1. Drücken Sie die Tasten Strg + Umschalt + Entf.
  2. Wählen Sie bei „Zeitbereich“ den Eintrag „Alle Zeit“.
  3. Aktivieren Sie „Zwischengespeicherte Bilder und Dateien“ und klicken Sie auf „Jetzt löschen“.
  4. Ohne Tastenkürzel: Menü „Einstellungen und mehr“ (…) › Einstellungen › Datenschutz, Suche und Dienste › Browserdaten löschen › „Zu löschende Elemente auswählen“.

macOS

  1. Drücken Sie die Tasten ⌘ Cmd + ⇧ Umschalt + ⌫ Rücktaste.
  2. Wählen Sie bei „Zeitbereich“ den Eintrag „Alle Zeit“.
  3. Aktivieren Sie „Zwischengespeicherte Bilder und Dateien“ und klicken Sie auf „Jetzt löschen“.
  4. Ohne Tastenkürzel: Menü „Einstellungen und mehr“ (…) › Einstellungen › Datenschutz, Suche und Dienste › Browserdaten löschen › „Zu löschende Elemente auswählen“.
Edge-App Android und iPhone / iPad

Android / iOS

  1. Tippen Sie auf das Menü (…).
  2. Wählen Sie Einstellungen › Datenschutz und Sicherheit › „Browserdaten löschen“. Je nach App-Version heißt der Eintrag „Datenschutz“ oder „Privatsphäre“.
  3. Wählen Sie die Datentypen aus, die Sie löschen möchten, darunter den Cache (zwischengespeicherte Bilder und Dateien).
  4. Tippen Sie auf „Löschen“.
Edge Legacy Edge Version 12 bis 18 (EdgeHTML, Windows 10)

Windows 10

  1. Drücken Sie die Tasten Strg + Umschalt + Entf – oder öffnen Sie das Menü (…) › Einstellungen › „Zu löschende Elemente auswählen“.
  2. Aktivieren Sie „Zwischengespeicherte Daten und Dateien“.
  3. Klicken Sie auf „Löschen“.

Mozilla Firefox

Aktuelle Versionen Firefox ab Version 57

Windows / Linux

  1. Drücken Sie die Tasten Strg + Umschalt + Entf. Es öffnet sich „Neueste Chronik löschen“.
  2. Wählen Sie neben „Zeitraum“ den Eintrag „Alles“.
  3. Aktivieren Sie die Option „Cache“ und klicken Sie auf „OK“ bzw. „Jetzt löschen“.
  4. Ohne Tastenkürzel: Menü (☰) › Einstellungen › Datenschutz & Sicherheit › Cookies und Website-Daten › „Daten entfernen…“ (neuere Versionen: „Surf-Daten löschen“) › „Temporäre Dateien und Seiten im Cache“ › „Löschen“.

macOS

  1. Drücken Sie die Tasten ⌘ Cmd + ⇧ Umschalt + ⌫ Rücktaste. Es öffnet sich „Neueste Chronik löschen“.
  2. Wählen Sie neben „Zeitraum“ den Eintrag „Alles“.
  3. Aktivieren Sie die Option „Cache“ und klicken Sie auf „OK“ bzw. „Jetzt löschen“.
  4. Ohne Tastenkürzel: Firefox-Menü in der Menüleiste › Einstellungen › Datenschutz & Sicherheit › Cookies und Website-Daten › „Daten entfernen…“.

Android

  1. Tippen Sie auf das Dreipunkt-Menü und wählen Sie „Einstellungen“.
  2. Tippen Sie im Bereich „Datenschutz und Sicherheit“ auf „Browserdaten löschen“.
  3. Aktivieren Sie „Zwischengespeicherte Bilder und Dateien“.
  4. Tippen Sie unten auf „Browserdaten löschen“ und bestätigen Sie mit „Löschen“.

iPhone / iPad (iOS)

  1. Öffnen Sie das Menü und wählen Sie „Einstellungen“.
  2. Tippen Sie unter „Datenschutz“ auf „Datenverwaltung“.
  3. Aktivieren Sie „Cache“ und tippen Sie am Ende der Liste auf „Private Daten löschen“.
Ältere Versionen Firefox bis Version 56

Windows / Linux / macOS

  1. Drücken Sie die Tasten Strg + Umschalt + Entf (macOS: ⌘ Cmd + ⇧ Umschalt + ⌫ Rücktaste), wählen Sie „Alles“ und aktivieren Sie „Cache“.
  2. Ohne Tastenkürzel: Menü (☰) › Einstellungen › Erweitert › Netzwerk › „Zwischengespeicherte Webinhalte“ › „Jetzt leeren“.

Android (ältere App)

  1. Tippen Sie auf das Menü-Symbol und dann auf „Einstellungen“.
  2. Wählen Sie unter „Datenschutz & Sicherheit“ den Eintrag „Private Daten löschen“.
  3. Aktivieren Sie „Cache“ und tippen Sie auf „Daten löschen“.

Safari

Mac Safari 6 und neuer (macOS)

macOS

  1. Blenden Sie einmalig das Entwickler-Menü ein: Safari › Einstellungen › Erweitert › „Menü ‚Entwickler‘ in der Menüleiste anzeigen“.
  2. Wählen Sie in der Menüleiste „Entwickler“ › „Cache-Speicher leeren“ – oder drücken Sie ⌘ Cmd + ⌥ Alt + E.
  3. Alternativ (löscht auch Cookies): Safari › Einstellungen › Datenschutz › „Websitedaten verwalten…“ › „Alle entfernen“.
iPhone / iPad iOS 18 und neuer

iOS / iPadOS

  1. Öffnen Sie die „Einstellungen“ Ihres Geräts und tippen Sie auf „Apps“ › „Safari“.
  2. Scrollen Sie nach unten und tippen Sie auf „Verlauf und Websitedaten löschen“. Bestätigen Sie den Zeitraum mit „Verlauf löschen“.
  3. Nur Websitedaten ohne Verlauf: Safari › „Erweitert“ › „Websitedaten“ › „Alle Websitedaten entfernen“.
iPhone / iPad (älter) iOS 17 und älter

iOS / iPadOS

  1. Öffnen Sie die „Einstellungen“ Ihres Geräts und wählen Sie „Safari“.
  2. Tippen Sie auf „Verlauf und Websitedaten löschen“ und bestätigen Sie.
  3. Nur Websitedaten: „Erweitert“ › „Websitedaten“ › „Alle Websitedaten entfernen“ und mit „Entfernen“ bestätigen.
Ältere Versionen Safari 5 und älter (Mac und Windows)

macOS

  1. Öffnen Sie das Menü „Safari“ und wählen Sie „Cache leeren…“.
  2. Klicken Sie anschließend auf „Leeren“.

Windows

  1. Drücken Sie die Tasten Strg + Alt + E.
  2. Klicken Sie anschließend auf „Leeren“.

Opera

Aktuelle Versionen Opera ab Version 36

Windows / Linux / macOS

  1. Drücken Sie die Tasten Strg + Umschalt + Entf (oder: Opera-Menü › Einstellungen › Datenschutz & Sicherheit › „Browserdaten löschen…“).
  2. Wählen Sie als Zeitraum „Gesamte Zeit“ bzw. „Beginn der Zeit“.
  3. Aktivieren Sie „Zwischengespeicherte Bilder und Dateien“ und klicken Sie auf „Browserdaten löschen“.
Frühere Chromium-Versionen Opera 15 bis 35

Windows / Linux / macOS

  1. Klicken Sie auf den Opera- bzw. Menü-Knopf in der Titelleiste des Browserfensters.
  2. Klicken Sie im Menü „Einstellungen“ auf „Internetspuren löschen…“.
  3. Aktivieren Sie die Option „Den kompletten Cache löschen“.
  4. Klicken Sie unten im Fenster auf „Löschen“.
Ältere Versionen Opera bis Version 12 (Presto)

Windows

  1. Opera 11 und 12: Opera-Menü › Einstellungen › „Private Daten löschen…“ (Tastenkürzel Strg + Umschalt + Entf).
  2. Opera 9 und 10: Menü „Extras“ › „Private Daten löschen…“.
  3. Klicken Sie auf „Detaillierte Optionen“, aktivieren Sie „Gesamten Cache löschen“ und klicken Sie auf „Löschen“.

Brave

Aktuelle Versionen Brave für Computer und Android

Windows / Linux

  1. Drücken Sie die Tasten Strg + Umschalt + Entf – oder geben Sie brave://settings/clearBrowserData in die Adressleiste ein.
  2. Ohne Tastenkürzel: Menü (☰) › Einstellungen › Zusätzliche Einstellungen › Datenschutz und Sicherheit › „Browserdaten löschen“.
  3. Wählen Sie einen Zeitraum (z. B. „Gesamte Zeit“) und aktivieren Sie „Zwischengespeicherte Bilder und Dateien“.
  4. Klicken Sie auf „Daten löschen“.

macOS

  1. Drücken Sie die Tasten ⌘ Cmd + ⇧ Umschalt + ⌫ Rücktaste – oder geben Sie brave://settings/clearBrowserData in die Adressleiste ein.
  2. Wählen Sie einen Zeitraum (z. B. „Gesamte Zeit“) und aktivieren Sie „Zwischengespeicherte Bilder und Dateien“.
  3. Klicken Sie auf „Daten löschen“.

Android

  1. Öffnen Sie in Brave die Einstellungen.
  2. Wählen Sie „Brave-Shields und Datenschutz“ › „Browserdaten löschen“.
  3. Wählen Sie die Datentypen (darunter den Cache) und tippen Sie auf „Browserdaten löschen“.

Vivaldi

Aktuelle Versionen Vivaldi für Computer

Windows / Linux

  1. Drücken Sie die Tasten Strg + Umschalt + Entf – oder öffnen Sie das Vivaldi-Menü › Werkzeuge › „Browserdaten löschen…“.
  2. Wählen Sie den Zeitraum „Alles“.
  3. Aktivieren Sie „Cache“ (und „Anwendungs-Cache“) und klicken Sie auf „Löschen“.

macOS

  1. Drücken Sie die Tasten ⌘ Cmd + ⇧ Umschalt + ⌫ Rücktaste – oder wählen Sie im Menü „Werkzeuge“ den Eintrag „Browserdaten löschen…“.
  2. Wählen Sie den Zeitraum „Alles“.
  3. Aktivieren Sie „Cache“ (und „Anwendungs-Cache“) und klicken Sie auf „Löschen“.

Samsung Internet

Samsung Internet Android (Galaxy-Geräte)

Android

  1. Öffnen Sie Samsung Internet und tippen Sie unten rechts auf das Menü-Symbol (☰).
  2. Tippen Sie auf „Einstellungen“ › „Persönliche Browserdaten“ (je nach Version „Persönliche Daten“) › „Browserdaten löschen“.
  3. Aktivieren Sie „Cache“ bzw. „Zwischengespeicherte Bilder und Dateien“.
  4. Tippen Sie auf „Löschen“ bzw. „Daten löschen“ und bestätigen Sie.

Bei älteren Versionen finden Sie die Funktion unter Einstellungen › Datenschutz und Sicherheit › „Browserdaten löschen“.

Internet Explorer

Internet Explorer 9 bis 11 Windows

Windows

  1. Drücken Sie die Tasten Strg + Umschalt + Entf – oder klicken Sie auf das Zahnrad › Sicherheit › „Browserverlauf löschen…“.
  2. Entfernen Sie das Häkchen bei „Daten der bevorzugten Websites beibehalten“ und aktivieren Sie „Temporäre Internetdateien und Websitedateien“.
  3. Klicken Sie auf „Löschen“.

Microsoft empfiehlt statt Internet Explorer den Browser Edge (bei Bedarf mit „Internet Explorer-Modus“).

Internet Explorer 7 und 8 Windows

Windows

  1. Internet Explorer 8: Drücken Sie Strg + Umschalt + Entf oder wählen Sie „Sicherheit“ › „Browserverlauf löschen…“.
  2. Internet Explorer 7: „Extras“ › „Internetoptionen“ › Registerkarte „Allgemein“ › im Bereich „Browserverlauf“ auf „Löschen…“.
  3. Wählen Sie „Temporäre Internetdateien“ und klicken Sie auf „Löschen“.
Internet Explorer 6 Windows

Windows

  1. Wählen Sie „Extras“ › „Internetoptionen“ › Registerkarte „Allgemein“.
  2. Klicken Sie im Bereich „Temporäre Internetdateien“ auf „Dateien löschen…“.
  3. Aktivieren Sie „Alle Offlineinhalte löschen“ und bestätigen Sie mit „OK“.
